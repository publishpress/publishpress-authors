# Introduction to Author Fields

Table of Contents

- [Getting Started With Author Fields](#h-getting-started-with-author-fields)
- [How Authors Can Add Information to Fields](#h-how-authors-can-add-information-to-fields)

The [PublishPress Authors](https://publishpress.com/links/authors) plugin allows you to customize the user details for each author. This is possible with the “Author Fields” feature. These fields can be displayed using the [Author Boxes](https://publishpress.com/links/author-box) feature.

## Getting Started With Author Fields [#](#h-getting-started-with-author-fields)

There are several fields available in the Free version of the Authors plugin:

- First Name
- Last Name
- Email
- Website
- Job Title

![Author Fields](https://docs-media.metaslider.com/publishpress-authors/author-fields-8a5848c4e8.webp)

In the Pro version of [PublishPress Authors](https://publishpress.com/links/authors), you will find more default field including these:

- Facebook
- Twitter
- Instagram
- Linkedin
- YouTube
- TikTok

![Author Fields in PublishPress Authors Pro](https://docs-media.metaslider.com/publishpress-authors/authors-pro-fields-70b4e275b5.webp)

In the Pro version of PublishPress Authors, you can also add your own fields to author profiles. The available field types are:

- Text
- Multiline Text
- WYSIWYG Editor
- Link
- Email

## How Authors Can Add Information to Fields [#](#h-how-authors-can-add-information-to-fields)

Your users will be able to update the information in the fields by visiting the “Author Profile” link in the WordPress admin menu. In the image below, you can see these fields:

- First Name
- Last Name
- Email
- Website
- Job Title

![Author Profiles](https://docs-media.metaslider.com/publishpress-authors/author-profile-1-db8100cf08.webp)
