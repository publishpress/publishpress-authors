# Default Layouts for Author Boxes

The [PublishPress Authors](https://publishpress.com/links/authors) plugin a feature called “[Author Boxes](https://publishpress.com/links/author-box)” to display your author profiles. There are several default layouts. You can customize these, or add your own layouts.

- Simple List
- Inline with Avatars
- Inline
- Centered
- Boxed

These options are available everywhere you can display your authors, including in the [PublishPress Authors](https://publishpress.com/links/authors) widgets, shortcodes, Author Pages, and more. You will find them under the “[Author Boxes](https://publishpress.com/links/author-box)” screen.
