# Add a Search Box to the Author Lists (Pro)

This feature requires the Pro version of the PublishPress Authors plugin.

In the Pro version of [PublishPress Authors](https://publishpress.com/links/authors) it’s possible to add to show a search box on your Author List. If you have a busy site with many authors, you want to add a search box to the Authors List.

This feature can be controlled from the “Search” tab of the Author Lists feature.

- **Show Search Box**: This displays a simple search box.
- **Search Field Dropdown**: This adds a dropdown menu that allows users to search on specific Author Fields. You can choose one or more fields that users can select to search with.

![Search box Author Lists](https://docs-media.metaslider.com/publishpress-authors/search-tab-lists-b429f05f6a.webp)

You can extend this search option and allow users to search on custom fields. This feature supports all core WordPress fields and all custom fields in [PublishPress Authors Pro](https://publishpress.com/links/authors).
