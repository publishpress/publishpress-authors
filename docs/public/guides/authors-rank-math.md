# PublishPress Authors and Rank Math SEO

[PublishPress Authors](https://publishpress.com/links/authors) integrates with the popular [Rank Math SEO](https://wordpress.org/plugins/seo-by-rank-math/) plugin.

There are two ways that [PublishPress Authors](https://publishpress.com/links/authors) integrates with Rank Math.

- First, Rank Math can [show author schema data](https://publishpress.com/knowledge-base/schema-data-for-authors/) from profiles in PublishPress Authors. This schema data will not be visible in normal search results, but search engines will find this information and use it to identify the authors.
- Second, you can use PublishPress Authors profile information in the author page meta data shown by Rank Math. This screenshot below shows the “Authors” tab in Rank Math. If you use the %name% token, this will pull the profile information from PublishPress Authors.
