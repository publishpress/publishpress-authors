# Automatically Create Author Profiles

Table of Contents

- [Automatically Create Author Profiles for New Users](#0-toc-title)
- [Automatically Create Author Profiles for Existing Users](#1-toc-title)

When you install the [PublishPress Authors](https://publishpress.com/links/authors), the plugin will automatically attempt to create profiles for all existing post authors.

[PublishPress Authors](https://publishpress.com/links/authors) also allows you to create author profiles automatically for new and existing users. This allows you to create profiles for users who have not yet written posts.

## Automatically Create Author Profiles for New Users [#](#0-toc-title)

- Go to Authors > Settings.
- Choose roles in the “Automatically create author profiles” box. For example, in the image below, I want author profiles for all new Administrators and Editors.

This option will automatically create author profiles when new users are created in these roles.

![Automatically create author profiles](https://docs-media.metaslider.com/publishpress-authors/create-user-profiles-bb586e8280.webp)

## Automatically Create Author Profiles for Existing Users [#](#1-toc-title)

If your site already has existing users who have not written posts, you can also use this option to quickly create profiles for those users.

- Choose the user roles in the “Automatically create author profiles” option
- Click the “Maintenance” tab.
- Click “Create PublishPress Authors Profile” button in the Maintenance tab. So if you have selected “Administrator” and “Editor” in the “Automatically create author profiles” option, this will create author profiles for any users who have not yet written posts.

![Create PublishPress Authors Profiles for all users in a role](https://docs-media.metaslider.com/publishpress-authors/create-author-profiles-for-a-role-f1fea7f06b.webp)
