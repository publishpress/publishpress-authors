# Author Lists Options

Table of Contents

- [General](#0-toc-title)
- [Users](#1-toc-title)
- [Options (Pro version)](#2-toc-title)
- [Search (Pro version)](#3-toc-title)

The Author Lists feature in the [PublishPress Authors](https://publishpress.com/links/authors?swcfpc=1) plugin allows you to show a custom display of authors. In this guide, we’ll show you some of the options available in the Author Lists feature.

## General [#](#0-toc-title)

The “General” tab provides the key settings for the Authors List:

- **Title**: This is the title of the Authors Lists that will appear on the frontend. Leave this blank for no title.
- **Layout**: Choose the layout for each author profile. There are two custom layouts: “Authors Index” and “Authors Recent”.
- **Layout Columns**: You can choose to display the author profiles across multiple columns.
- **Group By**: This is available only for the “Authors Index” layout. You can choose the field to use for grouping authors. For example, you can choose to group authors by “First Name” or “Last Name”.

![General Tab Author Lists](https://docs-media.metaslider.com/publishpress-authors/general-tab-lists-80ec907f8a.webp)

## Users [#](#1-toc-title)

The “Users” tab allows you to limit the authors shown in the Author List. You can choose to show specific user roles, author types, or individual authors.

In the Pro version of [PublishPress Authors](https://publishpress.com/links/authors), you can can choose to exclude specific user roles, author types, or individual authors.

This feature requires the Pro version of the PublishPress Authors plugin.

![Author List show or exclude](https://docs-media.metaslider.com/publishpress-authors/author-list-show-exclude-2fa354843c.webp)

## Options (Pro version) [#](#2-toc-title)

This feature requires the Pro version of the PublishPress Authors plugin.

The “Options” tab is available in the Pro version of [PublishPress Authors](https://publishpress.com/links/authors):

- **Authors Per Page**: Set the number of authors to show per page.
- **Show Empty**: Enable this option to show all authors, including those without any posts.
- **Order By**: This allows you to control how authors are ordered in the Author List. The options are “Name”, “Post Counts”, “First Name”, and “Last Name”.
- **Order**: This connected to the “Order By” field. You can choose “Ascending” or “Descending”
- **Last Article Date**: You can limit the author list to users with a published post within a specific time. This option accepts date values such as 1 week ago, 1 month ago, 6 months ago, 1 year ago etc.

![Author Lists Options tab](https://docs-media.metaslider.com/publishpress-authors/options-tab-lists-a5cef981bd.webp)

## Search (Pro version) [#](#3-toc-title)

This feature requires the Pro version of the PublishPress Authors plugin.

The “Search” tab enables you to show a search box on your Author List.

- **Show Search Box**: This displays a simple search box.
- **Search Field Dropdown**: This adds a dropdown menu that allows users to search on specific Author Fields. You can choose one or more fields that users can select to search with.

![Search box Author Lists](https://docs-media.metaslider.com/publishpress-authors/search-tab-lists-b429f05f6a.webp)
