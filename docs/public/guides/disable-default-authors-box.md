# Using the Default Authors Box Below Posts

By default, the [PublishPress Authors](https://publishpress.com/links/authors) plugin will add an authors’ box below your content. This image shows how the author profiles appear by default:

![Author profiles appearing by default](https://docs-media.metaslider.com/publishpress-authors/authors-default-post-7b4429c179.webp)

However, there are [many ways to show your authors](https://publishpress.com/docs/display-multiple-authors/) and you don’t need to rely on this default box.

If you want to enable or disable the default authors box, here’s how to do it:

- Go to Authors > Settings.
- Click the “Display” tab.
- Check or uncheck the box labelled “This will display the authors box at the end of the content.”
- Click “Save Changes”.

![Author Boxes tab](https://docs-media.metaslider.com/publishpress-authors/author-boxes-tab-b5bde28fae.webp)
