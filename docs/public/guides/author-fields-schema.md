# Author Fields Schema

[PublishPress Authors](https://publishpress.com/links/authors) provide custom schema data for your Author Fields. You can use any valid schema data that can find on [the Schema.org page](https://schema.org/Person). For example, some of them that could be useful are:

- [alumniOf](https://schema.org/alumniOf) – If you have author fields like “University”, you can use “alumniOf” schema to input an organization that the person is an alumni of.
- [worksFor](https://schema.org/worksFor) – If you have author fields like “Company”, you can use “worksFor” schema to input an organizations that the person works for.
- [birthPlace](https://schema.org/birthPlace) – If you have author fields like “Hometown”, you can use “birthPlace” schema to input the place where the person was born.

![Schema Property author fields](https://docs-media.metaslider.com/publishpress-authors/author-fields-schema-property-f1c34319c2.webp)

When you check it using a tool such as [https://validator.schema.org](https://validator.schema.org) you will be able to see something like this:

![Schema validation PublishPress Authors](https://docs-media.metaslider.com/publishpress-authors/author-fields-schema-validator-f7f815dce9.webp)

PublushPress Authors integrates with the [Yoast SEO](https://wordpress.org/plugins/wordpress-seo/) or [Rank Math SEO](https://wordpress.org/plugins/seo-by-rank-math/) plugins to show schema data for your authors.

If you have the [PublishPress Authors](https://publishpress.com/links/authors) plugin installed, plus either Yoast or Rank Math, the schema data will be available automatically. No configuration is needed.
