# Templates for Author Category Boxes (Pro)

Table of Contents

- [How to Use The Author Category Boxes](#0-toc-title)[Custom Box #1](#1-toc-title)[Custom Box #1 (Code)](#2-toc-title)[Custom Box #2](#3-toc-title)[Custom Box #2 (Code)](#4-toc-title)

This feature requires the Pro version of the PublishPress Authors plugin.

In [PublishPress Authors](https://publishpress.com/links/authors), you can customize your own [Author Boxes](https://publishpress.com/links/author-box) by following [this guide](https://publishpress.com/knowledge-base/author-boxes-theme-templates/). That tutorial also works for [Author Category](https://publishpress.com/links/author-categories) Boxes. So in this post, we provide two samples of custom templates that you can apply for your [Author Category](https://publishpress.com/links/author-categories) Boxes.

## How to Use The Author Category Boxes [#](#0-toc-title)

To apply these custom templates, please make sure to follow the steps in this documentation: [Author Boxes and Custom Templates](https://publishpress.com/knowledge-base/author-boxes-theme-templates/).

Downloaded the code from the Github Gist below and upload according to the [custom theme documentation](https://publishpress.com/knowledge-base/author-boxes-theme-templates/). The name we choose for the file in this screenshow below was `my-author-categories.php`.

![Uploading a custom author template](https://docs-media.metaslider.com/publishpress-authors/custom-theme-7135ad1417.webp)

Once that file is uploaded, you can choose your template inside the [PublishPress Authors](https://publishpress.com/links/authors) Settings:

![Choosing a new Authors Categories theme](https://docs-media.metaslider.com/publishpress-authors/choose-author-categories-box-cd63212424.webp)
