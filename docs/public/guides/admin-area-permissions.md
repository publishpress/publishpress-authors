# Settings Permissions in PublishPress Authors

The [PublishPress Authors](https://publishpress.com/links/authors) plugin has permissions that allow you to control access to the plugin’s features and settings.

You can control which user roles have these permissions by installing the [PublishPress Capabilities](https://publishpress.com/capabilities/) plugin. After installing the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin, follow these steps:

- Go “Capabilities” in the WordPress admin area.
- In the top-left corner, choose the role you want to modify. In this screenshot below, we’re modifying the “Editor” role.
- Go to the “Taxonomies” tab. All the Authors in the [PublishPress Authors](https://publishpress.com/links/authors) plugin are stored as taxonomies. So if you check the “Manage” box, users in the “Editor” role will be able to manage Authors.

![Authors Taxonomy](https://docs-media.metaslider.com/publishpress-authors/authors-taxonomy-c22a25f6b5.webp)

Next, go to the “PublishPress Authors” tab. This image shows the permissions for PublishPress Authors tab:

- **ppma_manage_custom_fields**: this controls access to the “Fields” screen (only applies to Pro version).
- **ppma_edit_post_authors**: this controls who can add and edit authors to posts.
- **ppma_manage_layouts**: this controls access to the “Layouts” screen (only applies to Pro version).
- **ppma_edit_own_profile**: this controls who can access their “Authors Profile” link.
- **ppma_manage_author_categories**: this controls access to the “[Author Categories](https://publishpress.com/links/author-categories)” screen.

![PublishPress Authors Capabilities](https://docs-media.metaslider.com/publishpress-authors/plugin-capabilities-authors-70112e07fc.webp)
