# Create Author Profiles for Existing WordPress Users

In this guide for the [PublishPress Authors](https://publishpress.com/links/authors) plugin, we’ll show you how to set up author profiles for your current users.

- Go to “Authors” in your WordPress admin menu.
- Choose the “Registered Author With User Account” tab.

![Choose Author creation option](https://docs-media.metaslider.com/publishpress-authors/create-new-author-3f32d4fbe3.webp)

- In the “Select Author Account” option, choose any existing WordPress account.
- In the “Display name publicly as” option, enter a name for your new author profile.

Once the author profile exists, you’ll be able to see both “Edit User” and “Edit Author Profile” links. This tells you that the user is successfully linked to the author profile. Their information will be automatically pulled from the user account and added to the author profile.

![Edit Author Profile links](https://docs-media.metaslider.com/publishpress-authors/edit-author-profile-links-e7e13f457d.webp)

When this user logs into the site they will now be able see an “Author Profile” link in the WordPress admin menu.

![Publishpress Authors Link](https://docs-media.metaslider.com/publishpress-authors/publishpress-authors-link-75f284bef2.webp)

When writing a post, users will now be to select this new author profile and attach it to posts, as in the image below:

![Author profile box in post editor](https://docs-media.metaslider.com/publishpress-authors/authors-box-new-setting-33b8b9f39b.webp)
