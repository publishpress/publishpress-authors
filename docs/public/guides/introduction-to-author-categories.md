# Introduction to Author Categories

Table of Contents

- [Using Categories for Author](#h-different-types-of-author)

Author Categories is a feature in the [PublishPress Authors](https://publishpress.com/links/authors) plugin. It allows you to have different *types* of authors for WordPress posts. This enables you to give different types of credit to the all the people who work on your content.

## Using Categories for Author [#](#h-different-types-of-author)

The easiest way to see how the Author Categories feature works is to see some examples. One of the simplest examples is distinguishing between the writer and the editor of a post. This screenshot below shows two authors. One is a “Contributor” and one is an “Editor”.

Here’s an example from a parenting blog using different terminology. The post is “Written” by one person, but “Medically Reviewed” by another person.

This third screenshot shows a more complex example. There is the main writer, the person who updated the post, and the person who reviewed the post.

![Author Categories Type 2](https://docs-media.metaslider.com/publishpress-authors/author-types-2-1-96234265e0.webp)

## How to Use Author Categories [#](#h-how-to-use-author-categories)

The “Author Categories” feature is available in both the Free and Pro versions of [PublishPress Authors](https://publishpress.com/links/authors). You’ll find a “Author Categories” screen where you can add, remove, enable, and disable the different categories. There are four default categories:

- Author
- Coauthor
- Reviewer
- Editor

Only the “Author” category is enabled by default. You can click the “Quick Edit” link under any Author Category to enable it.

![Author Categories box](https://docs-media.metaslider.com/publishpress-authors/author-categories-screen-2-e3c0091eed.webp)

You can add authors to these categories while you are editing each post. This gives you the flexibility to place authors into different categories for different posts. When you have enabled more than one category, the “Authors” metabox on the post editing screen will now look like this screenshot below.

![Author Categories Metabox](https://docs-media.metaslider.com/publishpress-authors/post-edit-categories-d036449d30.webp)

## How to Show Author Categories [#](#h-how-to-show-author-categories)

In the Free version of PublishPress Authors, you can show the category on the Author’s profile. The Author Category will not show by default and must be added to your [Author Boxes](https://publishpress.com/links/author-box). You can do this by checking the box for “Show Author Categories”.

In this screenshot below, we’ve added the category next to the “Display Name”.

![Author boxes with categories](https://docs-media.metaslider.com/publishpress-authors/author-categories-preview-df18214222.webp)

The screenshot below has another, similar example. This time we’re using the “Inline with Avatars” layout.

![Author categories inline with avatars](https://docs-media.metaslider.com/publishpress-authors/inline-with-authors-c1b90f72e8.webp)

You will find that the “Show Author Categories” option is available elsewhere inside the [Author Boxes](https://publishpress.com/links/author-box) settings.You will find it inside the “Author Fields” area, as in this next screenshot.

![Show Author Categories](https://docs-media.metaslider.com/publishpress-authors/author-categories-fields-7826bc3bee.webp)
