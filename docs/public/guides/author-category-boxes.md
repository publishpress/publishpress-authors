# Add New Author Category Boxes (Pro)

This feature requires the Pro version of the PublishPress Authors plugin.

[PublishPress Authors Pro](https://publishpress.com/links/authors) has a feature that allows you do more with [Author Categories](https://publishpress.com/links/author-categories). You can create an “[Author Categories](https://publishpress.com/links/author-categories) Box”. This is a display format for your images that is specifically designed to group authors together in their categories.

![](https://docs-media.metaslider.com/publishpress-authors/new-categories-box-3b30b1531d.webp)

When you create an Author Categories box, this will produce a list layout with the authors grouped by category. This screenshot below shows three categories: Authors, Coauthor, and Reviewers.

![](https://docs-media.metaslider.com/publishpress-authors/pro-author-category-af6e6d52c9.webp)

There are four displays available, and you can also choose to utilize the default [Author Box](https://publishpress.com/links/author-box) layouts.

![](https://docs-media.metaslider.com/publishpress-authors/different-author-category-layouts-e2e437ff32.webp)

This next screenshot shows the same five authors but using the “Simple Name [Author Category](https://publishpress.com/links/author-categories) Block” layout. I’ve included a change to the “Grouping Display Style” option. The “Flex” option results in the authors being organized into three columns.

![Simple Name Author Category Block layout](https://docs-media.metaslider.com/publishpress-authors/simple-name-author-fe3c7c5f1f.webp)

If you change the layout to “Boxed”, you get the same three column layout, but with more author details.

![Boxed layout for author categories](https://docs-media.metaslider.com/publishpress-authors/group-author-box-1c63198687.webp)

It’s possible to completely customize the displays you see in this screenshots. The [Author Boxes](https://publishpress.com/links/author-box) come with many display options that cover font, font size, colors, layouts, and more. And if you prefer to use your own code, you can also [create your own Author Display templates](https://publishpress.com/knowledge-base/author-boxes-theme-templates/).
