# Author Categories Boxes (Pro)

Table of Contents

This feature requires the Pro version of the PublishPress Authors plugin.

The [PublishPress Authors Pro](https://publishpress.com/links/authors) plugin a feature called “[Author Categories](https://publishpress.com/links/author-categories) Boxes” to display your author profiles. There are several default layouts. You can customize these, or add your own layouts.

- Boxed
- Two Columns
- List Authors Inline
- List Authors Block
- Simple Name Author Block
- Simple Name Authors Inline

These options are available everywhere you can display your authors, including in the [PublishPress Authors](https://publishpress.com/links/authors) widgets, shortcodes, Author Pages, and more. You will find them under the “[Author Boxes](https://publishpress.com/links/author-box)” screen.
