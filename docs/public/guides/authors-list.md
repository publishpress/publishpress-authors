# Introduction to Author Lists

Table of Contents

- [Author Index List](#0-toc-title)
- [Author Recent List](#1-toc-title)
- [Using Other Layouts for Authors List](#h-using-other-layouts-for-authors-list)

The Author Lists feature in the [PublishPress Authors](https://publishpress.com/links/authors) plugin allows you to show a custom display of authors.

This feature comes with a variety of different views and configuration options. You’ll find this feature by going to “Authors” then “Author Lists” in your WordPress admin menu. You’ll find two default lists.

![Authors List screen](https://docs-media.metaslider.com/publishpress-authors/authors-list-c2aa032e4b.webp)

## Author Index List [#](#0-toc-title)

The “Author Index” view can organize your authors alphabetically. This screenshot below shows a preview of this “Author Index” view. There are a row of letters on the top of this display. If you click on any of the letters, you’ll be able to drill down to view only the authors whose names begin with that letter.

![Author Index List layout](https://docs-media.metaslider.com/publishpress-authors/author-index-list-1ec25a8972.webp)

*Authors Index*

## Author Recent List [#](#1-toc-title)

The “Author Recent List” view allows you to show your authors, together with their most recent posts. This image below shows the “Author Recent” view. Each author has their name, profile image, and five most recent posts.

![Author Recent layout](https://docs-media.metaslider.com/publishpress-authors/author-recent-8d3bb64629.webp)
