# Calling Author Profile Fields With Code

It is possible to use your own code to fetch data from author profiles in the [PublishPress Authors](https://publishpress.com/links/authors) plugin.

There are two types of author profile field.

The first type of field are the core fields provided by WordPress. You can [find the code for these fields on WordPress.org](https://developer.wordpress.org/reference/functions/get_the_author_meta/#description). These fields include the First Name, Last Name, Email, Website, and Biographical Info.
