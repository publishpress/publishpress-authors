# Author Categories Schema

With the [Author Categories](https://publishpress.com/links/author-categories) feature in [PublishPress Authors](https://publishpress.com/links/authors), you can add Schema.org data to each category. The list of available options is on t[his Schema.org page](https://schema.org/Person). Some examples include:

- [publishedBy](https://schema.org/publishedBy)
- [reviewedBy](https://schema.org/reviewedBy)
- [readBy](https://schema.org/readBy)

In this example screenshot below, we’re adding the “reviewedby” property to uses in the “Medical Reviewer” category.

![medical reviewer](https://docs-media.metaslider.com/publishpress-authors/author-category-schema-property-c2c1bd5f78.webp)

When you test it using tool such as https://validator.schema.org you will see something like this:

![Author Categories Schema](https://docs-media.metaslider.com/publishpress-authors/reviewedby-schema-property-edited-0672672d4f.webp)

PublushPress Authors integrates with the [Yoast SEO](https://wordpress.org/plugins/wordpress-seo/) or [Rank Math SEO](https://wordpress.org/plugins/seo-by-rank-math/) plugins to show schema data for your authors.

If you have the [PublishPress Authors](https://publishpress.com/links/authors) plugin installed, plus either Yoast or Rank Math, the schema data will be available automatically. No configuration is needed.
