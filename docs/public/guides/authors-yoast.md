# PublishPress Authors and Yoast SEO

[PublishPress Authors](https://publishpress.com/links/authors) integrates with the popular [Yoast SEO](https://wordpress.org/plugins/wordpress-seo/) plugin.

There are two ways that [PublishPress Authors](https://publishpress.com/links/authors) integrates with Yoast.

- First, Yoast can [show author schema data](https://publishpress.com/knowledge-base/schema-data-for-authors/) from profiles in PublishPress Authors. This schema data will not be visible in normal search results, but search engines will find this information and use it to identify the authors.
- Second, you can use PublishPress Authors profile information in the author page meta data shown by Yoast. This screenshot below shows the “Authors” tab in Yoast. If you use the “Term title” token, this will pull the author name from PublishPress Authors.
