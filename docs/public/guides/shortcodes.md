# Author Box Shortcode

Table of Contents

- [How to Use the Author Box Shortcode](#h-how-to-use-the-author-box-shortcode)
- [How to Customize the Author Box Shortcode](#h-how-to-customize-the-author-box-shortcode)

The [PublishPress Authors](https://publishpress.com/authors/) plugin allows you to show author profiles using a shortcode.

With the [Author Box](https://publishpress.com/links/author-box) shortcode you can display the profile of all the authors attached to a specific post.

## How to Use the Author Box Shortcode [#](#h-how-to-use-the-author-box-shortcode)

This is the simplest version of the shortcode:

```

                
                    

                    
                    
                                                
                        
                                                                                                                                    
                                                                                                                        
                                                                                                                                                                                                                                                                                                                                                            
                                                                                                                    
                                                                                                                                                                                    
                                                                    
                                                                                                                                                                                                                                                                                                                                                                                                                            
                                                                                                                                    
                                                            
                                                            
                                                                Steve Burge                                                                                                                                                                                                    
                                                                                                                                            
                                                                                                                                                    Steve is the founder of PublishPress. He's been working with open source software for over 20 years. Originally from the UK, he now lives in Sarasota in the USA. This profile is generated by the PublishPress Authors plugin.
                                                                                                                                                
                                                                                                                                                                                                    
                                                                                                                                
                                                                                                                            
                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                        
                                                                            
                                                                                                                        
                        
                                            
                    
                    
                
                            
        
```

Here is how this shortcode appears when added to the Gutenberg editor in a block:

There is one final option to mention. This is mostly useful if you’re using a theme or page builder to customize the Author profile pages you find at URLs such as /author/username/. You can use the following shortcode on the authors page to display the profile of the current author. You just need to add the parameter `archive="true"`:

```

                
                    

                    
                    
                                                                                    Author #
                                                                            
                        
                                                                                                                
                        
                                            
                    
                    
                
                            
        
```

If you are having problems showing [PublishPress Authors](https://publishpress.com/links/authors) on author profile pages, you can use this shortcode below. The argument archive=”1″ forces the plugin to retrieve the Author from the profile page and not any other posts on the same screen.

```

                
                    

                    
                    
                                                                                    Author #
                                                                            
                        
                                                                                                                
                        
                                            
                    
                    
                
                            
        
```
