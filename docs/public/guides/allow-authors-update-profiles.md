# Allow Authors to Update Their Profiles

If a user has an author profile linked to their account, they will see an “Author Profile” screen in the WordPress admin menu. They can update their profile information here and it will update on the front of your site.

![Edit your Authors profile](https://docs-media.metaslider.com/publishpress-authors/avatar-field-a2a7ddac2b.webp)

*Authors Edit My Profile*

If users click the “Avatar” tab, they’ll be able to control their own profile image. They can use the Gravatar service, or upload their own custom image.

![Edit your Authors avatar](https://docs-media.metaslider.com/publishpress-authors/avatar-field-1-663f5a71b5.webp)

You can give users access to this new Authors screen in several ways including these:

- You can [manually create Author profiles for them](https://publishpress.com/knowledge-base/mapping-users-to-author-profiles/).
- You can [automatically create profiles for new users in certain roles](https://publishpress.com/knowledge-base/automatically-create-author-profiles/).
