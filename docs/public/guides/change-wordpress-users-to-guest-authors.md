# Change WordPress Users to Guest Authors

With the [PublishPress Authors plugin](https://publishpress.com/authors/), it is possible to change WordPress users into Guest Authors. Please note that we support two kinds of guest authors. This guide will focus on the first option:

1. Guest Author with User Account (recommended).
2. Guest Author with No User Account (a legacy option).

Here’s how to convert the authors to guests:

- Go to the “Authors” area.
- Select the boxes for all the users that have imported.
- In the dropdown, choose “Convert to Registered Author with User Account”.
- Click “Apply”.

![Convert to Registered Author](https://docs-media.metaslider.com/publishpress-authors/convert-fab9a527fd.webp)

Now you can verify that everything is working correctly. Go to the “Posts” screen and test to make sure the authors are still with their correct posts.
