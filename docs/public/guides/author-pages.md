# Introduction to Author Pages

Table of Contents

- [How to Enable Author Pages](#0-toc-title)
- [Default WordPress Author Pages](#1-toc-title)

The Author Pages feature in the [PublishPress Authors](https://publishpress.com/links/authors?swcfpc=1) plugin allows you to replace the default author pages provided by WordPress.

The WordPress core provides author pages that display the posts written by each author. These author pages will normally be located at a URL like this `/author/username/`. [PublishPress Authors](https://publishpress.com/links/authors) can replace the default WordPress author pages. The URLs of the pages will not change, but you can customize the pages using the settings on this screen.

## How to Enable Author Pages [#](#0-toc-title)

To use the “Author Pages” feature provided in the [PublishPress Authors](https://publishpress.com/links/authors) plugin follow the steps below.

- Go to “Authors”, then “Author Pages”.
- Check the box “Enable author pages”.

## Default WordPress Author Pages [#](#1-toc-title)

PublishPress Authors does support the default WordPress author pages. However, sometimes there are complications, often involving third party themes. This is because PublishPress Authors [does not use the normal WordPress approach to storing author information](https://publishpress.com/knowledge-base/authors-data-backup/). The most common issue is that wrong name appears on author pages. You can fix this [by modifying your theme](https://publishpress.com/knowledge-base/modify-theme-output-authors/). However, if you don’t want to modify your theme, you can use the “Author Pages” feature provided by PublishPress Authors.
