# How to Add Author  Fields (Pro)

Table of Contents

- [Add a New Field](#h-add-a-new-field)
- [Enter Data for The New Field](#h-enter-data-for-the-new-field)
- [Add the Field to Your Layout](#h-add-the-field-to-your-layout)

This feature requires the Pro version of the PublishPress Authors plugin.

It is possible to expand the Author profiles for the [PublishPress Authors plugin](https://publishpress.com/authors) with custom fields. This is a feature of the Pro version.

By default, [PublishPress Authors](https://publishpress.com/links/authors) allows you to enter basic user details for each author:

- First Name
- Last Name
- Avatar
- Email
- Website
- Job Title
- Biographical Info

If you’re using [PublishPress Authors Pro](https://publishpress.com/links/authors), you can add your own fields to author profiles. The current field options are:

- Text
- Multiline Text
- WYSIWYG Editor
- Link
- Email

## Add a New Field [#](#h-add-a-new-field)

- Go to Authors > Author Fields.
- Click “New Author Field”.

![](https://docs-media.metaslider.com/publishpress-authors/new-author-field-f891aaf4eb.webp)

- Enter a title for your field. In the image below, I choose “Personal Website”.
- Enter a “Field Slug”. This is key because it is how you will add your field to the frontend layout.
- Choose a “Field Type”.
- You can also enter a description. This appears under the fields in the admin area and helps users understand their choice.

![](https://docs-media.metaslider.com/publishpress-authors/personal-website-field-e9e694156e.webp)

## Enter Data for The New Field [#](#h-enter-data-for-the-new-field)

- Go to “Authors” in your WordPress admin.
- Click “Edit Author Profile” for an author.
- Fill in your new field.

## Add the Field to Your Layout [#](#h-add-the-field-to-your-layout)

The final step in adding fields is to include them in your [Author Box](https://publishpress.com/links/author-box).

- Go to “Authors” then “[Author Boxes](https://publishpress.com/links/author-box)“.
- Go to the “Author Fields” tab.
- In this area, you can customize each field. For example, in this screenshot below we are customizing the “Personal Website” field:

![Author Boxes customization](https://docs-media.metaslider.com/publishpress-authors/author-field-custom-5ce3ab7205.webp)
