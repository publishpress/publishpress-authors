# How to Include a Design for PublishPress Authors in Your Theme

If you are a theme designer, it is possible to include your own designs for [PublishPress Authors](https://publishpress.com/links/authors) in your theme.

The [PublishPress Authors](https://publishpress.com/links/authors) plugin is free to use. You can add a notification to your theme, asking users to install the Authors plugin.

To create your own theme, [follow this guide](https://publishpress.com/knowledge-base/author-boxes-theme-templates/). Your custom layout for author profiles can be placed here:

```
/your-theme-name/publishpress-authors/author-boxes/my-custom-author-box.php
```

If you have any questions about integrating Authors in your theme, please feel free to contact us for help.
