# Add New Social Links to Author Profiles (Pro)

This feature requires the Pro version of the PublishPress Authors plugin.

This guide shows how to add a new field using [PublishPress Authors Pro](https://publishpress.com/links/authors).

We will show you how to add new social link to [author profiles](https://publishpress.com/knowledge-base/mapping-users-to-author-profiles/). This example we’ll use is a field for the “Mastodon” social network.

To get started, we’re going to add some new social icons to [PublishPress Authors](https://publishpress.com/links/authors).

- Go to Authors > Settings > Advanced.
- Check the “Font Awesome icons” box. This will load Font Awesome icons for use in [Author Boxes](https://publishpress.com/links/author-box).

Now we can add our new social field:

- Go to “Authors” then “Author Fields” in your WordPress admin menu.
- Click “New Author Field”.
- Create your new field for [social links](https://publishpress.com/links/social-links). In the image below, I’m using the “Link” field type and selecting “Yes, this is a Social Profile”.
- Click “Publish”.

![Adding a new social field](https://docs-media.metaslider.com/publishpress-authors/add-mastodon-7ad8c92687.webp)

*New Author Field*

- Go to “Author Profile” and enter a URL for your social link. We will use this to test our new field.

![Creating a new social profile link in PublishPress Authors](https://docs-media.metaslider.com/publishpress-authors/enter-social-url-dc6ca0d1d8.webp)

- Go to “Authors”, then “[Author Boxes](https://publishpress.com/links/author-box)“.
- Edit the layout you want to add [social links](https://publishpress.com/links/social-links) to. In the example, below I’ll use the “Boxed” layout.

![Editing Author Fields in PublishPress Authors](https://docs-media.metaslider.com/publishpress-authors/boxed-layout-1982a31976.webp)

*Author Layouts*

- Go to the “Author Fields” tab.
- Check the box to customize your new field.

![Mastodon customize field](https://docs-media.metaslider.com/publishpress-authors/mastodon-customize-216f48b578.webp)

You will immediately see the link to your social profile in the preview at the top of the screen:

![New social profile link in PublishPress Authors](https://docs-media.metaslider.com/publishpress-authors/mastodon-link-88018f5536.webp)

Now you can modify this link to make it more attractive.

- Go to [FontAwesome.com](https://fontawesome.com) and search for the best icon for your profile.
- In this example, I’ll use [this Mastodon icon](https://fontawesome.com/icons/mastodon?s=&f=brands).
- Enter the HTML code for the icon into the “Display Icon” field, as in this screenshot below.
- I’ve also changed the “Display” setting to be simply “Field Icon”.

![Field settings for Author Fields](https://docs-media.metaslider.com/publishpress-authors/mastodon-icon-added-279feb5787.webp)

- Finally, I’d recommend choosing “link” for the “HTML Tag” field.

![New Mastodon field](https://docs-media.metaslider.com/publishpress-authors/html-link-field-86282dab9d.webp)

This will now complete the process and turn your icon into an active link. You may want to change the color settings for the field to match your site design:

![New Mastodon social links](https://docs-media.metaslider.com/publishpress-authors/new-field-added-6c766ab9b4.webp)
