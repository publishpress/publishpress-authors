# How to Choose Author Avatars

The [PublishPress Authors](https://publishpress.com/links/authors) plugin allows you to select an avatar / profile image for each author.

These avatars can be controlled by going to the “Authors” link in the WordPress admin menu. Edit an author, and click the “Avatar” tab.

There are three choices available:

- Use the default avatar for all users.
- Use the image associated with the author’s email in the [Gravatar](https://gravatar.com) service.
- Upload a custom image.

![](https://docs-media.metaslider.com/publishpress-authors/avatar-choices-60ddf95517.webp)

You can check the “Custom image” box and upload a profile image for just this author:

![](https://docs-media.metaslider.com/publishpress-authors/select-avatar-9fe81a51ae.webp)

You can also set a default avatar for all authors. Go to “Authors”, then “Settings”. Click the “Author Profiles” tab and choose a “Default Avatar”.

![Choose a default avatar](https://docs-media.metaslider.com/publishpress-authors/default-avatar-2428b96329.webp)
